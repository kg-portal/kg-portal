⏱ Feste Zeiten & WhatsApp-Bestätigung

Feste Arbeitszeiten je Mitarbeiter speichern → ganzen Monat ausfüllen (nur leere Tage, ohne Feiertage) → der KG Agent schickt jedem seinen Monat per WhatsApp → „Ja“ oder Korrektur → zur Frist wird gesperrt und der Bericht kommt per Mail.

So geht's: 1. „Feste Zeiten“ öffnen, Wochentage anhaken, Beginn/Ende/Ort wählen, speichern. 2. „Monat ausfüllen“. 3. „WhatsApp senden“ – jeder Tag mit Datum, von Damlas Diensthandy, Deutsch/Türkisch. 4. Antwort „Ja“ → ✓ Ja. Korrektur („15.10. krank“) → der KG Agent trägt sie ein (✏️ korrigiert). Nicht verstanden → ⚠ unklar: bitte prüfen/anrufen. 5. Frist 12:00 Uhr: alle Monate gesperrt, Bericht an info@ (keine Antwort = so übernommen). „Rückgängig“ löscht nur automatisch eingetragene Tage, die niemand verändert hat.
